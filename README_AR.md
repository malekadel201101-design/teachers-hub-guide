# دليل التعلّم — مشروع مستقل لدعم اكتشاف Teachers Hub

هذا مشروع ويب ثابت (Static Website) مبني باستخدام **HTML وCSS وJavaScript**. لا يحتاج إلى تثبيت Python أو أي مكتبات أو قاعدة بيانات.

## محتويات المشروع

- `index.html` — الصفحة الرئيسية باللغة العربية.
- `guide.html` — دليل عربي مفصل لاختيار المدرس.
- `en/index.html` — الصفحة الرئيسية باللغة الإنجليزية.
- `en/guide.html` — الدليل الكامل باللغة الإنجليزية.
- `assets/styles.css` — التصميم المتجاوب للهاتف والكمبيوتر.
- `assets/site.js` — أداة إنشاء قائمة المقارنة، ونسخ الأسئلة، وتحديث السنة.
- `assets/favicon.svg` — أيقونة الموقع.

## معاينة الموقع على جهازك

1. فك ضغط الملف.
2. افتح `index.html` في Chrome أو أي متصفح.
3. جرّب أداة المقارنة، وروابط الانتقال بين العربية والإنجليزية، وصفحة الدليل.

لا تحتاج إلى تشغيل أو كتابة أي كود.

## النشر على الإنترنت

هذه الحزمة جاهزة كملفات موقع ثابت. لكي تصبح متاحة للجميع، يجب رفع **محتويات المجلد** إلى خدمة استضافة صفحات ثابتة. اختر خدمة تسمح باستضافة static sites، واتبع شروط العمر والحساب الخاصة بها، واستعن بولي أمرك في إنشاء الحساب أو ربط النطاق إذا كان ذلك مطلوبًا.

بعد النشر:

1. اختبر رابط الموقع على الهاتف والكمبيوتر.
2. استبدل أي روابط داخلية إذا غيّرت بنية الملفات.
3. أضف عنوان الموقع المنشور (الدومين النهائي) إلى `canonical` و`hreflang` وملف `sitemap.xml` قبل إرساله إلى Google Search Console. لا تضع عنوانًا تخمينيًا؛ استخدم الرابط الحقيقي بعد النشر.
4. أضف الموقع في Google Search Console باستخدام طريقة التحقق المتاحة لك أو لولي أمرك، ثم أرسل خريطة الموقع عند تجهيزها.
5. انتظر الزحف والفهرسة؛ لا يوجد ضمان لوقت محدد أو ترتيب معين.

## ملاحظات مهمة

- هذا مشروع مستقل من محبّي Teachers Hub، وليس موقعًا رسميًا ولا يمثل إدارة المنصة.
- لا يستخدم شعار Teachers Hub أو صور مدرسيها أو بياناتهم دون إذن.
- أداة المقارنة إرشادية فقط؛ لا تبحث في قاعدة بيانات Teachers Hub ولا توصي بمدرس بعينه.
- معلومات المنصة الواردة هنا ملخصة من صفحاتها الرسمية وقت إعداد المشروع، وقد تتغير. راجع المصدر الرسمي قبل نشر تحديثات.
- لا تضف تقييمات مزيفة أو روابط مزعجة أو صفحات مكررة بهدف التلاعب بنتائج Google. الأفضل نشر محتوى أصلي مفيد ومشاركته مع المهتمين فعلًا.
